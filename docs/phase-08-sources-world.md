# Phase 8 place-source review: Lagos, Tokyo, and New York City

Reviewed on **2026-11-01** for the local six-city class-project catalog. The staged file is `.tmp/release-world.json`: 24 records, eight per city, two restaurants per city. This file is prepared for owner integration; it does not itself activate new destinations in the app.

## What the sources establish

Venue/operator, government, university, and official tourism pages were used to check each named place, its location, and the limited factual description. Descriptions are short original paraphrases. No Google Maps/Places listings, photographs, reviews, or stored provider database were copied into this catalog.

The money values are **illustrative per-person planning allowances, not live prices, guaranteed admission quotes, exchange-rate conversions, or meal offers**. Every record carries this distinction and a review date. General free entry is marked zero only where a primary source supports it; paid facilities, purchases, bookings, and transport are not silently included. Current prices, access, opening days, and reservations must still be checked with the operator.

## Content and redistribution boundary

The staged JSON contains factual place identifiers/addresses, source links, brief authored descriptions, and explicitly illustrative planning amounts. It includes no downloaded source-page content, imagery, logos, map tiles, or reviews. Source links are attribution and verification references; they are not a blanket grant to redistribute the linked site's material. No image license has been obtained by this research task. The photo stage must perform its own per-asset licensing/credit checks.

Free and paid classifications are not live availability checks. The planner does not currently enforce opening calendars, travel distances, reservations, accessibility, dietary needs, or safety. This source review does not change those limitations.
